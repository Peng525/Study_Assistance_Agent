# 开发环境配置

> 版本：v1.0 | 日期：2026-08-23
> 适用阶段：Phase 0

## 前置条件

### 操作系统
- Windows 10/11（用户当前环境）
- 需安装 Git for Windows（Git Bash 用于 hook 脚本执行）

### 运行时
- **Python 3.13+**（用户已有 3.13.12）
- **Node.js 20 LTS+**（Vite 5 要求 Node 18+）
- **ffmpeg**（Whisper 依赖，需手动安装并加入 PATH）

### 包管理器
- pip（Python，随 Python 安装）
- npm（Node.js，随 Node 安装）

## 后端配置（FastAPI）

### 1. 创建虚拟环境
```bash
cd backend
python -m venv venv
# Windows 激活
venv\Scripts\activate
# Git Bash 激活
source venv/Scripts/activate
```

### 2. 安装依赖
```bash
pip install fastapi uvicorn sqlalchemy httpx python-dotenv
pip install bcrypt PyJWT cryptography
pip install webvtt-py pysrt pymupdf python-pptx
pip install openai-whisper
```

### 3. 环境变量配置
复制 `.env.example` 为 `.env`，填入真实值：
```bash
cp .env.example .env
```

`.env` 关键配置项：
- `LLM_BASE_URL` - 阿里云百炼平台地址
- `LLM_API_KEY` - 大模型API key
- `LLM_MODEL_NAME` - 模型名（qwen-plus）
- `ADMIN_USERNAME` / `ADMIN_PASSWORD` - 管理员账号
- `USER_USERNAME` / `USER_PASSWORD` - 用户账号
- `JWT_SECRET` - JWT密钥
- `APP_PORT` - 后端端口（默认8000）

### 4. 启动后端
```bash
uvicorn main:app --reload --port 8000 --host 127.0.0.1
```

## 前端配置（React + Vite）

### 1. 安装依赖
```bash
cd frontend
npm install
```

### 2. 启动前端
```bash
npm run dev
```
默认端口 5173，通过 Vite proxy 代理 `/api` 到后端 8000。

## ffmpeg 安装（Whisper 依赖）

### Windows 安装方法
1. 下载：https://ffmpeg.org/download.html → Windows builds → gyan.dev
2. 解压到如 `C:\ffmpeg`
3. 将 `C:\ffmpeg\bin` 加入系统 PATH
4. 验证：`ffmpeg -version`

## Whisper 模型下载

首次使用时自动下载 medium 模型（769MB）到 `~/.cache/whisper/`。
如需提前下载或更换模型，管理台提供模型管理功能。

## 常见问题

### Q: git push 连接超时？
A: 检查代理设置，绕过代理：`HTTP_PROXY= HTTPS_PROXY= git push`

### Q: Whisper 生成字幕很慢？
A: CPU 运行 medium 模型 1h 视频约 30-60min。如有 GPU 会快很多（~3min）。或降级用 small 模型。

### Q: hook 脚本不生效？
A: 确认 `.workbuddy/settings.json` 配置正确，且 Git Bash 已安装（Windows hook 强制用 Git Bash）。
